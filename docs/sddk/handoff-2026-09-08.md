## Patterns worth remembering for cycle 400

1. **Locator default timeout pitfall** (learned in cycle 399 P8):
   `isVisible()` and `click()` without explicit `{ timeout }` use
   Playwright's default (30-60s). When target is intentionally absent,
   always add explicit short timeout.

2. **`page.reload()` preserves query params** (learned in cycle 398,
   reused in cycle 399): use `page.goto("/")` instead of
   `page.reload()` to drop `?skip-welcome=1` (or any other query).

3. **Tag-at-archive pattern**: tag on cycle commit → push → archive
   commit (docs) → retag to archive commit → push → SHAs-update
   sidecar (regular commit, NOT amend) → push → done. The tag peel
   is the archive commit; SHAs-update lives on top.

4. **Phantom bridge detection**: when a test asserts
   `typeof window.__xxx === "function"` and __xxx doesn't exist, the
   fix is to assert the REAL bridge that captures the test's intent,
   not to invent the phantom bridge in production. Cycle 399 P2
   example: `__selectEntity` (phantom) → `__setSelectedEntityId` (real).

5. **A-lite vs A-min routing**:
   - A-min: single bounded change, no fork
   - A-lite: multiple coordinated changes, default for "bounded but
     several-files" work
   - cycle 400 should be A-min (single REQ, ≤1 task)
