# v0.87 Roadmap — Architecture Foundation

## Objective

Create enforceable architecture boundaries before adding more strategic surface area.

## PR sequence

### PR1 — CI reality
- add Rust/WASM/frontend smoke workflows;
- make `main` required checks explicit;
- add architecture check script skeleton;
- align CONTRIBUTING with real workflow.

### PR2 — `editor-model`
- create crate;
- move StableId/LocalId and pure scene/asset/logic values in small groups;
- re-export from legacy paths;
- prove no Bevy/WASM deps.

### PR3 — Clock/Id ports
- add traits and production/test implementations;
- replace new ID generation first;
- migrate existing call sites incrementally.

### PR4 — `editor-application` + ProjectStore
- introduce application crate and ports;
- wrap existing OPFS behavior in adapter-facing interface;
- add in-memory contract implementation/tests.

### PR5 — EditorSession phase 1
- move scene registry/doc/history state;
- single composition-root access path;
- remove corresponding globals.

### PR6 — EditorSession phase 2
- assets/logic/cache/validation state;
- remove `from_globals()` processor dependencies.

### PR7 — Transaction Kernel v1
- extract common history/batch/rollback primitives;
- wrap existing scene/asset/logic logs;
- introduce `ChangeSet` IDs/origin/effects.

### PR8 — Typed backend foundation
- create `EditorBackend` interface;
- migrate one vertical slice (Scene) end-to-end;
- add fake backend test utility;
- forbid new raw global bridge functions.

### PR9 — remaining bridge feature migration
- Asset/Logic/Runtime/Validation/Code APIs;
- reduce `App.tsx` to composition/features.

## Exit criteria

- architecture CI green;
- pure model tests no Bevy/WASM compile;
- no production use case reaches old global state for migrated domains;
- current project corpus loads/saves identically;
- existing E2E critical paths still pass;
- no user-facing feature regression accepted as “temporary architecture work”.
