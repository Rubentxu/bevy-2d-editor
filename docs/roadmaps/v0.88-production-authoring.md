# v0.88 Roadmap — Production 2D Authoring

## Objective

Turn the architectural foundation into faster, more coherent 2D creation workflows.

## Epics

### Direct Manipulation
- viewport box selection;
- gizmos;
- snapping/guides;
- align/distribute;
- gesture grouping into one command;
- layer lock/visibility/isolate.

### World Workspace
- WorldDocument;
- free/grid layout;
- level links/entrances;
- validation;
- navigation to level.

### Scope of Change
Every relevant inspector/edit flow can distinguish instance, selected instances and Scene Asset definition. Override consequences are previewed before broad edits.

### Project filesystem mode
Implement/validate the chosen browser filesystem/native companion adapter and Git-friendly format behavior.

### Recipes v1
Ship a small high-quality set rather than a large shallow catalog:

1. Platformer Character;
2. Top-Down Character;
3. Door + Key;
4. Checkpoint/Respawn;
5. Moving Platform;
6. Follow Camera.

## Exit criteria

A developer can construct and connect several levels, create common actors/interactions through recipes, tune placement visually and store/review the project through a normal repository workflow.
