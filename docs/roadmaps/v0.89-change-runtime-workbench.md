# v0.89 Roadmap — Change & Runtime Workbench

## Objective

Unify review, history and runtime reasoning.

## Epics

### Change Workbench
- semantic diff;
- affected-resource tree;
- scope control;
- validation/effect panels;
- partial approval with revalidation;
- checkpoint/rollback.

### Runtime Causality
- mapping/provenance graph;
- logic activation trace;
- rebuild/hot-reload cause;
- source links;
- recent ChangeSet links.

### Runtime Apply-Back
- authorability schema metadata;
- baseline/delta capture;
- instance/definition scope;
- workbench review;
- undo.

## Exit criteria

The answer to “why is this entity doing this?” can be navigated from the runtime entity to its definition/instance/logic/source, and selected play-mode tuning can be safely persisted.
