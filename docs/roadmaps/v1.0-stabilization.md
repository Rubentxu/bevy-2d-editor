# v1.0 Roadmap — Stabilization and Product Readiness

## Goal

Declare a stable first product contract rather than simply reaching a feature count.

## Required work

### Data safety
- format/migration support matrix;
- backup/recovery;
- interruption/crash tests for writes;
- import/reimport recovery.

### Performance
Benchmark corpus for:

- 10k entities;
- large tile levels;
- multi-level worlds;
- large asset catalogs;
- logic graphs;
- project search/retrieval.

### UX
- coherent onboarding/tutorial project;
- consistent shortcuts/menus/palette;
- keyboard accessibility;
- clear mode/context breadcrumbs;
- actionable validation messages.

### Developer ecosystem
- extension API compatibility policy;
- agent tool protocol versioning;
- project format versioning;
- contribution architecture guide.

### Release engineering
- signed/versioned artifacts as applicable;
- reproducible release pipeline;
- changelog/release notes generated from verified state;
- rollback/hotfix procedure.

## v1.0 definition of done

A user can create a multi-level 2D project, build reusable actors, wire common gameplay, import art/data, run and inspect the game, safely tune/apply changes, use Git-visible project files and optionally use an agent to perform reviewed editor operations without compromising data integrity.
