# v0.90 Roadmap — Agent Runtime Foundation

## Objective

Introduce Rig as orchestration infrastructure behind stable editor tools.

## Sequence

1. `editor-protocol` tool/request/result types;
2. `agent-runtime` crate with provider abstraction through Rig;
3. tool registry with read-only Scene/Validation/Runtime tools;
4. manager + Scene specialist;
5. ChangeSet planning tool;
6. `/v1/propose` compatibility shim;
7. approval/policy integration;
8. observability and deterministic mock-agent tests.

## Required constraints

- no direct store imports;
- no raw file writes from agent code;
- every mutation is a ChangeSet;
- destructive source operations remain human-mandatory initially;
- mock providers cover CI without external API dependency.
