# v0.92 Roadmap — Ecosystem, SDK and Import/Reimport

## Objective

Prove extensibility and external-tool interoperability.

## Sequence

1. internal extension registry/capability permissions;
2. recipe extension implementation;
3. validator extension implementation;
4. ExternalSource/provenance core;
5. Aseprite importer/reimporter;
6. LDtk importer/reimporter;
7. Tiled importer/reimporter;
8. extension compatibility/version documentation.

## Exit criteria

At least three built-in capabilities use the same extension interfaces intended for future third-party use, and reimport conflict handling is safe enough for normal production workflows.
