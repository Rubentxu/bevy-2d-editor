# v0.92 Roadmap — Ecosystem, SDK and Import/Reimport

## Objective

Prove extensibility and external-tool interoperability.

## Sequence

| # | Item | Status | Notes |
|---|------|--------|-------|
| 1 | internal extension registry/capability permissions | ✅ DONE (v0.92) | `ExtensionManifest`, `Capability`, `Permission` types; `ExtensionRegistryPort` trait + `Arc<Mutex<dyn ExtensionRegistryPort>>` in `EditorSession` |
| 2 | recipe extension implementation | ✅ DONE (v0.92) | `builtin.logic-recipes` extension with `Capability::Recipes` |
| 3 | validator extension implementation | ✅ DONE (v0.92) | `builtin.scene-validator` extension with `Capability::Validators` |
| 4 | ExternalSource/provenance core | ✅ DONE (v0.93) | ADR-0041 implemented; `ExternalSource`, `ExternalSourceKind`, `SourceMapping`, `OwnershipRule`, `ProvenanceDiff`, `ConflictPolicy` types in `editor-model` |
| 5 | Aseprite importer/reimporter | ✅ DONE (v0.93) | `builtin.aseprite`; JSON parser → Level SceneAsset with `LevelLayer::Tile`; PNG + Aseprite JSON → `resources/`; sidecar `.meta.json` provenance |
| 6 | LDtk importer/reimporter | ✅ DONE (v0.93) | `builtin.ldtk`; one doc per level; `LevelLayer::IntGrid` + `LevelLayer::Auto`; version range 1.0.0–1.5.0 |
| 7 | Tiled importer/reimporter | ✅ DONE (v0.93) | `builtin.tiled`; JSON only (TMX/XML rejected); embedded tileset → `TilesetAsset`; template → `Fragment` doc |
| 8 | extension compatibility/version documentation | ✅ DONE (v0.93) | `ImporterVersion` + `ImporterVersionRange` wired in all importers; arch fitness gate added |

## Exit criteria

**Fully met:** Three built-in capabilities use the same extension interfaces (commands, recipes, validators ✅ from v0.92). Three importer extensions added (Aseprite, LDtk, Tiled ✅ from v0.93). Reimport conflict handling routes through ChangeWorkbench with `ApprovalPolicy::RequiresHuman` ✅.
