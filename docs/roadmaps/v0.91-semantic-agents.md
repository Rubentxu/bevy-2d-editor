# v0.91 Roadmap — Semantic Retrieval & Agent Workbench

## Objective

Move from an LLM proposal feature to project-aware multi-step assistance.

## Epics

- typed semantic index over resources, schemas, source, docs, diagnostics and recent accepted changes;
- retrieval policies by specialist/capability;
- Asset, Logic, Code, World and Runtime specialists;
- Change Workbench agent origin view;
- post-apply validation/runtime verification loops;
- repair/regenerate workflow;
- bounded background tasks for indexing, stale-reference audit and schema normalization suggestions.

## Success criteria

Agent answers and changes cite concrete editor resources/diagnostics, can explain expected impact before execution and can verify the applied outcome rather than assuming success.
